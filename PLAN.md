# Stream Plan

Build small tools that help us stream. Use Pop!_OS, Codex, and Copilot. Keep setup light and words brief.

## Build Next

- [ ] **Progress board:** Show the project, checklist, completed work, and next task. Save in the browser; import and export progress files.
- [ ] **OBS display:** Show the project name, current task, and break message on stream. Reuse the board's information where useful.
- [ ] **Chat doodads:** Try emotes, simple commands, and Channel Point rewards such as choosing editor colors. Check which Twitch features are available. Handle rewards manually at first.

Build one useful piece at a time. Add features as we need them.

## Each Stream

- **Before:** Pick a task. Check audio and screen readability.
- **During:** Follow the checklist. Read chat at natural pauses.
- **After:** Review the checklist together. Record finished work, checks, and blockers. Choose one next task.

## Before Relying on a Tool

Try its main job and check that saved work survives a restart. For the board, also check importing and exporting progress.
