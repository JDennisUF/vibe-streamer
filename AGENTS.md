# Stream workspace

This repository holds shared streaming guidance. Independent project repositories live under `projects/` and are ignored by this repository.

For stream preparation, project planning, stream coding, and end-of-stream reviews, read `.agents/skills/stream-vibe-coding/SKILL.md` relative to this file. Keep the workflow lightweight and follow the active project's own instructions and tooling.

Run project Git commands from that project's directory. Keep its checklist and session notes in its own repository. Change shared guidance here when the user requests a change that should apply across projects.
